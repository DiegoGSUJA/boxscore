# Boxscore

Portal informativo de baloncesto NBA desarrollado como proyecto personal de formación por un equipo unipersonal. No es un proyecto académico supervisado ni un producto comercial.

## Estado

Planificación y especificación inicial. El repositorio contiene documentación; no incluye todavía la aplicación implementada. Los requisitos permanecen como borrador, no como una línea base aprobada para implementación.

## Documentación

- [Contexto del proyecto](docs/PROYECTO_CONTEXTO.md).
- [Estado y próximos pasos](docs/ESTADO_PROYECTO.md).
- [Especificación inicial de requisitos](docs/REQUISITOS.md).

GitHub es la referencia documental. Incorporar un documento no aprueba automáticamente sus propuestas.

## Tecnologías de partida

Stack provisional: Java con Spring Boot, PostgreSQL y React con TypeScript. Docker Compose y GitHub Actions son prioridades de aprendizaje. Kubernetes se aplaza hasta después del MVP.

No están aprobados los proveedores, las fuentes o bibliotecas de acceso a datos, el alojamiento ni las versiones concretas.

## Límites

- Presupuesto de 0 euros, sin nuevas suscripciones ni pruebas que se conviertan en pago.
- Funcionamiento local prioritario; demo privada opcional y condicionada.
- Cuentas de usuario fuera del primer incremento propuesto.
- Viabilidad técnica y condiciones de uso de los datos pendientes de revisión.
- Sin afiliación con la NBA ni sus equipos. El proyecto no presupone autorización para usar datos, logos o recursos de terceros.
