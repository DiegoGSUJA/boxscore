# Boxscore

Portal informativo de baloncesto NBA, proyecto personal de formación de desarrollo unipersonal, sin supervisión académica obligatoria ni finalidad comercial.

## Situación

Requisitos funcionales 1.0, diseño UX 1.1 y diseño técnico inicial publicados. La preparación inicial está documentada; no hay aplicación implementada ni pruebas de software superadas acreditadas.

La revisión de datos identifica una señal restrictiva en la FAQ oficial de NBA Stats y cuestiones de uso no aclaradas. Ninguna fuente o biblioteca de acceso a datos queda aprobada.

Siguiente paso: comprobar el entorno y preparar el backend. Los primeros casos controlados usarán datos ficticios identificados; no habrá conexión NBA real mientras no se resuelva y apruebe la integración. Esto no sustituye la prioridad de evaluar datos reales ni declara terminado el incremento.

## Tecnologías y límites

Stack provisional: Java y Spring Boot, PostgreSQL, React y TypeScript. Docker Compose y GitHub Actions progresivos; Kubernetes después del MVP. Versiones y papel de persistencia por decidir.

Presupuesto de 0 euros, sin suscripciones nuevas ni pruebas que se conviertan en pago. Local prioritario; demo privada opcional y condicionada. Sin cuentas, directos, noticias ni gráficas en el primer incremento. Sin afiliación con NBA o equipos; no se presupone autorización para datos, logos o recursos de terceros.
